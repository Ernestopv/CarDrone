# Raspberry Pi Skill

## Purpose

Use this skill for tasks involving Raspberry Pi runtime, Raspberry Pi OS, ARM64 deployment, GPIO, PWM, camera devices, uStreamer, Linux device access, hardware permissions, and Raspberry Pi specific Docker behavior.

This skill complements:

- `spec-driven-development`
- `dotnet`
- `docker`

Use multiple skills together when the task overlaps domains.

---

# Platform Assumptions

Target platform:

```text
Raspberry Pi
Raspberry Pi OS / Debian-based Linux
linux/arm64
Docker Engine
```
